# Flimmer

Werbefreie Video-App für Android TV – im gewohnten Look mit Navigationsleiste, Filter-Chips und Video-Raster.

- **Keine Werbung:** Videos werden direkt geladen, eingeblendete Werbung gibt es nicht.
- **SponsorBlock:** Sponsoren-Abschnitte, Intros, Abo-Hinweise usw. werden automatisch übersprungen.
- **Kein Konto nötig:** Abos, Verlauf, Suchverlauf, „Später ansehen“ und Fortschritt werden nur auf dem Fernseher gespeichert.
- **Persönliche Startseite:** „Neu von deinen Kanälen“ und „Empfohlen für dich“ mit Videos von ähnlichen Creatorn – berechnet aus deinen Abos und deinem Verlauf.
- Bis 4K, Qualität und Tempo im Player wählbar, Fortsetzen wo du aufgehört hast, automatisch nächstes Video.

## Installieren

Auf dem Fernseher (z. B. mit der App „Downloader“) diesen Link öffnen:

https://github.com/erlinxrmj/Flimmer/releases/latest/download/Flimmer.apk

Die APK wird bei jeder Änderung automatisch neu gebaut (GitHub Actions).

## Bedienung

| Taste | Funktion |
|---|---|
| Links in der Leiste | Menü aufklappen |
| OK lange drücken auf Video | Später ansehen, Kanal, Abonnieren |
| Im Player ← / → | 10 Sekunden spulen |
| Im Player ↓ | Ähnliche Videos |
| Im Player ↑ | Titel, Kanal, Abonnieren, Qualität, Tempo |

Technik: [NewPipe Extractor](https://github.com/TeamNewPipe/NewPipeExtractor) (GPLv3), [SponsorBlock](https://sponsor.ajay.app), Media3/ExoPlayer.
